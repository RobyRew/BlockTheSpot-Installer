Spotify's latest release may be newer than the version tested with BlockTheSpot. For the tested 1.2.93.667.g7b5cc0ce build, use the BlockTheSpot app. Its version-specific downloads are provided through the LoadSpot catalog.

A few good things to know.

Does the app change versions automatically?

No. The default is pinned to Spotify 1.2.93.667.g7b5cc0ce, the latest version tested for this release. Newer versions require an explicit choice in Advanced options. A catalog or upstream script update does not change the default.

Can I undo the patch?

Yes. Choose “Restore original Spotify” in the app. The installer saves the original DLL before patching and restores the previous files if applying a patch fails.

Are Spotify downloads hosted here?

No. The Spotify buttons above go directly to Spotify's download servers. This site does not host, modify, or proxy Spotify installers. The BlockTheSpot installer itself is distributed through this repository's GitHub Releases.

Which Windows versions are supported?

The installer targets Windows x64 and uses .NET 10's native WPF Fluent theme. Windows 11 is recommended; supported Windows 10 editions also work. The EXE bundles its runtime. Spotify and the BlockTheSpot patch must both be x64.
